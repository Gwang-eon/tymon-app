Markdown 문서를 읽고 편집하는 tymon의 데스크톱 앱 배포 페이지입니다.
이 저장소에는 다운로드 안내와 버전별 변경 내역을 관리하며, 설치 파일은 GitHub Releases에서 제공합니다.

- 브랜드 페이지: https://tymon.app
- 웹 앱: https://note.tymon.app
- 현재 배포: **0.1.1 · 알파 · 2026-10-19**

macOS·Linux 설치 파일은 아직 공개하지 않았습니다.
앱 설치 파일과 웹 서비스는 별도로 업데이트되므로, 웹 반영 여부는 해당 릴리스 안내에서 확인해 주세요.

## 버전 정책

새 릴리스마다 패치 버전을 1씩 올립니다: `0.1.1 → 0.1.2 → 0.1.3`.
같은 릴리스의 웹과 데스크톱 앱은 같은 버전을 사용하며, 이미 공개된 버전의 파일을 다른 내용으로 교체하지 않습니다.
