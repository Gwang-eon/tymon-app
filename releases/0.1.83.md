# tymon 0.1.83 · Windows 알파

Windows x64 설치 파일입니다. 사이드 도킹 손잡이와 Hover 전환을 개선했습니다.

## 변경 내용

- 텍스트·아이콘 없는 10×84px 직선 손잡이로 변경해 모서리의 밝은 틈을 없앴습니다.
- 펼침·접힘 시 창 크기와 위치를 준비한 뒤 내용을 표시하도록 순서를 바꿨습니다.
- 반복 Hover, 접힘 도중 편집·고정, 일시적 창 제어 실패에 대한 처리를 보완했습니다.
- 키보드 펼침과 모션 감소 설정을 유지합니다.

## 설치 전 확인

- 코드 서명이 없는 알파 빌드입니다. Windows에서 보안 경고가 나타날 수 있습니다.
- **기존 앱에서 기기 전용 메모를 먼저 내보내고, 계정 메모는 동기화 완료를 확인해 주세요.** 앱 식별자가 이전 `com.edgememo.personal`에서 `com.tymon.tymon`으로 바뀌어 기존 로컬 데이터와 저장된 로그인이 자동 이전된다고 보장하지 않습니다. 새 앱에서 다시 로그인해야 할 수 있습니다.
- 일반 메모 백업이 첨부 원본이나 비밀 그룹 복구 키를 모두 포함하지는 않습니다. 필요한 파일과 복구 정보를 별도로 보관하고, 새 앱에서 확인하기 전 기존 데이터를 삭제하지 마세요.

## 검증 범위와 알려진 한계

- Windows 빌드와 자동 테스트 88개, Windows Chrome 모의 검사 47단계를 통과했습니다.
- 실제 설치 앱의 전환 품질·장시간 메모리 검수는 계속 진행 중입니다.
- 저장 지연 시 전체 메모 복사본이 대기열에 누적되는 문제와 영구적인 창 제어 무응답은 미해결입니다. 이번 버전이 모든 멈춤이나 메모리 문제를 해결한 것은 아닙니다.
- macOS·iOS·Android 설치 파일은 이 릴리스에 포함하지 않습니다.
