# tymon 0.1.83 · Windows 알파

사이드 도킹 손잡이와 Hover 펼침·접힘 전환을 개선한 Windows 알파 버전입니다.

[변경 내역과 설치 안내](https://tymon.app/ko/releases/0.1.83/)

## 주요 변경 사항

- 텍스트·아이콘 없는 10×84px 직선 손잡이로 변경했습니다.
- 펼침·접힘 시 창 크기와 위치를 준비한 뒤 내용을 표시하도록 순서를 조정했습니다.
- 반복 Hover와 편집·고정 중 전환, 일시적 창 제어 실패 처리를 보완했습니다.
- 키보드 펼침과 모션 감소 설정을 유지합니다.

## 설치 방법

1. 기존 앱에서 기기 전용 메모를 내보내고 계정 메모의 동기화 완료를 확인하세요. 첨부 원본과 비밀 그룹 복구 정보는 별도로 보관하세요.
2. 설치 파일을 다운로드한 뒤 아래 SHA-256과 비교하세요. 출처와 파일을 확인한 후 설치 여부를 결정하세요.
3. 편집 내용을 저장하고 기존 tymon 앱을 정상 종료한 뒤 설치 프로그램을 실행하세요.
4. 설치 후 필요하면 다시 로그인하세요. 기존 앱 식별자 com.edgememo.personal에서 com.tymon.tymon으로 변경되어 로컬 데이터와 저장된 로그인이 자동 이전된다고 보장하지 않습니다. 새 앱에서 메모를 확인하기 전 기존 데이터를 삭제하지 마세요.

## 알려진 문제

- 저장 지연 시 전체 메모 복사본이 대기열에 누적되어 메모리가 증가할 수 있습니다. 미해결 상태입니다.
- 네이티브 창 제어 IPC가 영구 무응답이면 제어 루프가 멈출 수 있습니다. 이번 버전은 모든 Hang을 해결하지 않습니다.

## 검증 범위

- Windows 빌드 및 자동 테스트 88개, Windows Chrome 모의 검사 47단계를 통과했습니다.
- 실제 설치 앱의 전환 품질과 장시간 메모리 안정성은 검증 완료 상태가 아닙니다.

## 설치 파일 확인

GitHub에서 설치 파일을 다운로드합니다. 코드 서명이 없는 알파 빌드로, Windows 보안 경고가 나타날 수 있습니다.

- 설치 파일명: `tymon_0.1.83_x64-setup.exe`
- 파일 크기: 14,385,307 B
- SHA-256: `06f1bb6d3e5a23a194492a6b782935c01e0df90134638aa9406822b200bb2fef`

배포 파일의 SHA-256과 아래 값을 비교하세요. 값이 다르면 설치를 중단하세요.

이 릴리즈에는 Windows x64 설치 파일만 포함됩니다. macOS·iOS·Android 설치 파일은 포함되지 않습니다.
