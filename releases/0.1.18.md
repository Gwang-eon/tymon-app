# tymon 0.1.18 · 알파

배포일: 2026-10-20

## 변경 사항

- 최신 공통 설정·계정 화면과 편집 도구를 Windows 앱에 반영했습니다.
- 설정에서 ‘항상 위’ 토글을 누를 때 설정 상단과 닫기 버튼이 화면 밖으로 밀리는 문제를 수정했습니다. 제목과 닫기 버튼은 유지하고 내용만 스크롤합니다.
- 접힌 가장자리 탭은 좌우에서 글자를 세로 방향으로, 위아래에서 가로 방향으로 표시합니다.
- Windows 창에 얇은 테두리와 활성 상태 강조를 추가하고 창 그림자를 활성화했습니다.
- 둥근 모서리와 투명 배경의 타이몬 아이콘을 앱 및 설치·제거 프로그램에 적용했습니다.

## 제공 파일

- `tymon_0.1.18_x64-setup.exe`: Windows x64 설치 파일
- `SHA256SUMS.txt`: 설치 파일 무결성 확인용 SHA-256

## 검증 및 현재 범위

- Windows Node·Rust로 설치 파일 빌드, 버전·타입·스타일·메모 전용 번들 검사 통과.
- 설정·창 제어·접힘 좌표·창 테두리 관련 자동 검사 25개 통과. 전체 테스트를 다시 실행한 결과는 아닙니다.
- Windows Chrome의 별도 설정 컴포넌트 화면에서 토글 클릭 후 상단과 닫기 버튼이 유지됨을 확인했습니다. 추가 키보드 검증은 러너 시나리오 오류로 중단했습니다.
- 설치 파일의 아이콘 리소스 6개 크기가 타이몬 ICO와 일치함을 확인했습니다.
- 새 설치본의 실제 계정 로그인, 창 바깥 그림자, 접힌 탭의 Windows 네이티브 동작 및 전체 설치 흐름은 아직 최종 검증하지 못했습니다.
- Windows 설치 파일은 코드 서명되지 않았습니다.
- macOS·Linux·모바일 패키지는 이번 릴리스에서 제공하지 않습니다.
- 이번 업데이트는 Windows 배포 파일에 대한 것입니다. 운영 웹·서버 배포와 DB 변경은 포함하지 않습니다.

0.1.1부터 0.1.18 사이의 버전 번호에는 소스·웹 릴리스가 포함되어 있으며, 이 저장소에 모든 중간 Windows 설치 파일이 공개된 것은 아닙니다.
