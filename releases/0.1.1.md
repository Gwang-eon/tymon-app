# tymon 0.1.1 · 알파

배포일: 2026-10-19

## 변경 사항

- 앱에서 제목과 본문을 함께 스크롤하는 문서 중심 읽기·편집 화면을 제공합니다.
- 데스크톱에서 창 이동·크기 조절과 가장자리 패널 전환을 지원합니다.
- 한쪽에서만 작성해도 서버의 빈 태그 등 저장 형식 정리를 다른 기기의 편집으로 오인하던 충돌 사본 생성 문제를 수정했습니다.
- 일반 저장에서는 충돌 사본용 해시를 계산하지 않아 불필요한 연산을 줄였습니다.
- 실제 내용 충돌은 양쪽 내용을 보존하며, 기존 충돌 사본을 자동 삭제하지 않습니다.

## 제공 파일

- `tymon_0.1.1_x64-setup.exe`: Windows x64 설치 파일
- `SHA256SUMS.txt`: 설치 파일 무결성 확인용 SHA-256

## 검증 및 현재 범위

- Windows 빌드와 버전 일치 검사 통과.
- 동기화·병합·잠금 관련 검사 49개 통과. 한쪽 작성·한쪽 열람 모델에서 20회 저장 중 충돌 사본이 생성되지 않고 원문과 추가 입력이 보존됨을 확인했습니다.
- 기능 변경 후 전체 검사: 335개 통과, 기존 UI 기대값 실패 2개, 제외 38개. 이후 버전 변경 빌드도 통과했습니다.
- 실제 계정에서 앱·웹을 동시에 사용하는 최종 확인은 남아 있습니다.
- Windows 설치 파일은 현재 서명되지 않았습니다. 설치 시 보안 경고가 나타날 수 있습니다.
- macOS·Linux 패키지는 아직 제공하지 않습니다.
- 이 릴리스 공개는 웹 운영 배포와 별개입니다. 공개 시점에 운영 웹의 0.1.1 반영은 아직 완료되지 않았습니다.
